# Contributing

Bug reports and ideas are welcome as [GitHub issues](https://github.com/ckpt-gthb/pfeilzaehler3000/issues).
Please keep questions public in the issues rather than in private messages.

## Pull requests

commercially (see `LICENSE` and `LICENSE-hardware`). So that a contribution can be part of both, by
opening a pull request you agree that:

1. You wrote the contribution yourself, or have the right to submit it, and it contains nothing
   under terms that would conflict with these.
2. You grant ckpt-gthb a perpetual, worldwide, non-exclusive, royalty-free, irrevocable licence to
   use, copy, change, distribute, sublicense and sell your contribution, as part of PfeilZaehler3000
   or otherwise, under any licence terms, including commercial ones.
3. You keep the copyright in your contribution; the project credits you in the pull request and the
   changelog.

If you don't agree, please don't open a pull request; describe the change in an issue instead.

## Before you start

- One change per pull request, with a short description of what it fixes and how you tested it
  (pod firmware, phone page, watch app or housing).
- Changes to the Bluetooth interface also update `docs/PROTOCOL.md`; user-visible changes update
  `CHANGELOG.md` and the build guide.
